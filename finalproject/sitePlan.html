Local Trail Finder

Local Trail Finder

Reason for Selection: I chose this name because my website helps people find local hiking trails.

Site Purpose

My website will help people find local hiking trails. My website will also give weather data for the location.

Scenarios

  • What hiking trails are available near my current location?
  • What is the difficulty level and distance of each trail?
  • What will the weather be like for the trail I want to hike?

Color Scheme

The website uses a natural outdoor inspired palette:

  • Primary: #2e7d32 - Forest green used for the header and accents.
  • Secondary: #1b5e20 - Deep green used for section backgrounds.
  • Accent: #f4e9d8 - Light tan used for borders and highlits.
  • Text #333 - Dark gray for readability.
  • Light Grey #f5f5f5 - Background and neutral areas.

Typography

The website uses two main fonts:

  • Montserrat: Used for headings to create a clean, bold look.
  • Roboto: Used for body text for readability and simplicity.
